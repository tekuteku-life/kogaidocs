## E-01 ナビゲーション・PWA・共有

| 機能名 | 要件・動作仕様 |
| :--- | :--- |
| **E-01-01 URLパラメータによるモード直接起動** | ・URLクエリパラメータ `mode`（例: `?mode=district`, `?mode=rep`, `?mode=neighbor`, `?mode=transfer`、および数値エイリアス `?mode=1`, `2`, `3`, `4`）を最優先で解釈して起動。<br/>・外部共有リンク（学校からの案内メール、LINE連絡等）を踏んだ際、役員や転入家庭がモード選択で迷うことなく、目的の画面を直接開くことが可能。<br/>・URLパラメータが指定されていない場合は、従来通り前回選択モード（`kogai_active_mode`）を復元。 |
| **E-01-02 モード指定URL共有機能** | ・ヘッダー右側の「🔗 アプリを共有」ボタンおよび各画面内の共有UIにおいて、特定モードを指定したURL（例: `https://.../?mode=transfer`）の生成・共有に対応。<br/>・Web Share API（`navigator.share`）、クリップボードコピー、コピー非対応時のプロンプト案内に対応。LINE・メール等のアプリ選択はOS共有先に依存する。 |
| **E-01-03 モード選択肢の動的折りたたみUX** | ・初期画面およびモード選択時、ヘッダー直下の4モード選択ボタンが自動的にコンパクトな「アクティブモード表示バッジ（例：`① 各地区役員モード ▼ [モード切替]`）」へと折りたたまれる。<br/>・スマートフォン等の狭小画面において、作業領域（名簿テーブルや入力フォーム）の視認性を劇的に向上。<br/>・バッジをクリックすると即座に4つのモード選択ボタンが展開され、いつでも自由に他モードへ移動可能。 |
| **E-01-04 前回選択モードの永続化と自動復元** | ・`switchTab(mode)` 実行時に選択されたモード（`district`, `rep`, `neighbor`, `transfer`）を `localStorage.setItem('kogai_active_mode', mode)` として永続化。<br/>・次回アクセス時やページ再読み込み時（`DOMContentLoaded`）、直前に開いていたモードを自動復元し、同一画面から作業をシームレスに再開可能（URLパラメータ指定時はURLパラメータが最優先）。 |
| **E-01-05 アプリ共有機能（PWA対応）** | ・PWAインストール後（スタンドアロン起動時）にブラウザのアドレスバーが消滅し、他の役員へURLを伝えられなくなる問題を解消。<br/>・ヘッダー右側に「🔗 アプリを共有」ボタンを常設。<br/>・Web Share API（`navigator.share`）により、LINE、メール、AirDrop等へワンタップでアプリURLおよび紹介文を送信可能。<br/>・Web Share API非対応ブラウザではクリップボード自動コピーおよびプロンプトフォールバック。 |
| **E-01-06 PWAバージョンチェック＆強制・手動アップデート機構** | ・**課題の根本解決**: PWAインストール（スタンドアロン起動）環境下において、Service WorkerやブラウザのHTTPキャッシュにより新版が反映されない問題を解消。<br/>・**`version.json` による静的バージョン公開**: サーバー直下に `version.json`（`version`, `updatedAt`, `description`）を配備。Service Workerキャッシュから除外し、常に最新の公開バージョンを取得。<br/>・**起動時自動チェック（オンライン時）**: アプリ起動時（DOMContentLoaded後1秒遅延）、`navigator.onLine` が有効であればキャッシュ無効化クエリ（`version.json?_t=${Date.now()}`）で自動取得。現在のバージョン（`CURRENT_APP_VERSION`）と比較し、最新版があれば確認ダイアログを表示し、OK選択時に強制アップデート。<br/>・**設定欄最下部の手動確認＆更新UI**: セキュリティ設定モーダル最下部に「📱 アプリバージョン情報」セクションを常設。現在のバージョン表示と「🔄 最新バージョンを確認・更新」ボタンを配備。手動クリック時に即時チェックし、最新版更新または最新状態フィードバックを提供（オフライン時はエラー通知）。<br/>・**保存完了後のアップデート (`performAppUpdate`)**: 更新実行前に必ず `saveDistrictLocal()`, `saveRepLocal()`, `saveNeighborLocal()`, `saveTransferLocal()` の完了を待つ。保存失敗を通知して更新を中止する。当該アプリscopeのキャッシュ削除および当該SW登録の解除を行い、キャッシュバスティングパラメータ付きURLで最新版を再取得。<br/>・**無限更新ループ防止セーフティガード（フェイルセーフ仕様）**: `performAppUpdate` 実行時に `sessionStorage` へ更新試行対象バージョン（`kogai_update_attempted_version`）および試行時刻（`kogai_update_attempted_time`）を記録。リロード後の自動チェック（`checkAppVersion(false)`）時に、直前の更新試行記録が存在しかつ現在の `CURRENT_APP_VERSION` が依然として `remoteVersion` 未満である場合、キャッシュ未反映やデプロイ遅延等と判断して**自動更新ダイアログの表示をスキップ（抑制）**。手動更新チェック（`checkAppVersion(true)`）ではスキップせず常に再試行可能。最新バージョンへの更新成功時には試行記録を自動消去。<br/>・**HTTPキャッシュ制御**: `navigator.serviceWorker.register('./sw.js', { updateViaCache: 'none' })` により、ブラウザのHTTPキャッシュをバイパスして `sw.js` の変更を確実に検知。 |
| **E-01-07 全削除操作における安全確認セーフティガード** | ・システム内の全削除ボタン（集約地区削除、スクゾ関係者削除、自治会役員削除、児童名簿削除、転入児童削除）において、誤タップ・誤クリックによる即時消失を完全に防止するため、確認ダイアログ（`confirm`）を表示する。ただし未入力の転入下書き行は確認なしで削除できる。<br/>・キャンセル時は配列操作を行わず安全に中断。対象の名前等をダイアログ内に明示して誤削除を防止。 |

## E-02 各地区役員モード

| 機能名 | 要件・動作仕様 |
| :--- | :--- |
| **E-02-01 地区名・班名リスト管理** | ・地区名（例：1丁目、緑ヶ丘）を入力。<br/>・地区名直下にカンマ区切りの班名リスト（例：`A班, B班, C班`）を登録。<br/>・班名リストから児童名簿および校外役員の「担当班」プルダウンが自動生成される。 |
| **E-02-02 校外役員管理（複数人対応）** | ・1地区あたり2人以上の役員（各班担当等）を登録可能。<br/>・氏名・ふりがなを「姓 / 名」別に入力。<br/>・役職、担当班、電話番号、メールアドレス、住所、封筒受取用児童情報（学年・組・氏名）を完備。<br/>・入力と連動してカードヘッダーがリアルタイム反映。役員削除時は確認ダイアログを表示。 |
| **E-02-03 自治会役員統合取込UI（トグル開閉UX）** | ・**トグル展開UX**: カード2ヘッダーの「📥 自治会データを統合」をクリックすると、カード本体を展開しつつ、自治会統合パネル（`#d-neighbor-import-panel`、初期 `display: none`）の表示/非表示をトグル開閉。<br/>・**名簿直結の「＋ 行を追加」ボタン配置**: 統合パネルの初期非表示化に伴い、自治会役員名簿テーブルの直前（上部ツールバー）および直下（テーブルフッター）の双方に「＋ 行を追加」ボタンを配置し、スクロール負担なく行追加が可能。<br/>・**役員行削除確認ダイアログ**: 自治会役員行の「×」削除ボタン押下時、役員名を表示して確認ダイアログ（`confirm('自治会役員「' + name + '」を削除しますか？')`）を表示。キャンセル時は削除を中断。<br/>・**スマートフォン最適化**: 横幅狭小画面でもボタンやテキストが途切れないレスポンシブな縦並びレイアウト。ファイル読込ボタン（`📁 ファイルから統合`）とクリップボード貼付入力欄（`#d-neighbor-paste-box`、`📥 貼付テキストから統合`）を明瞭に分離配置。<br/>・**地区名不一致時の保護**: 自治会データ内の地区名と自地区名が異なる場合、警告・確認ダイアログを表示し、キャンセル時は安全に中断。<br/>・現在の児童名簿や校外役員データを一切破壊せず、自治会役員テーブルのみを最新情報に更新。 |
| **E-02-04 転入児童データ統合取込（トグル開閉UX）** | ・カード3「児童名簿」ヘッダーまたはツールバーに「📥 転入児童データを統合」トグルボタンを配置。<br/>・取り込みパネル（`#d-transfer-import-panel`）を初期非表示（`display: none`）とし、トグル開閉により名簿一覧の邪魔にならない設計。<br/>・転入家庭から受け取った暗号化ファイル（`.txt`）または暗号化テキストを復号読込。<br/>・**班割り当て選択**: 既存班を初期値とする入力ダイアログで割り当てる班を入力する。<br/>・転入家庭の児童（1名または複数名兄弟姉妹）を自地区の児童名簿へ安全に追記・ソート・自動保存。 |
| **E-02-05 児童名簿管理（名簿直結ボタン配置・削除確認）** | ・学年（1〜6年）、クラス、班、氏名（姓/名）、ふりがな（せい/めい）、住所、電話番号、役職（班長/副班長/一般）、学区外フラグを入力。<br/>・**名簿直結ツールバー＆フッター**: 児童名簿テーブルの直前上部に「🔽 並び替え」「＋ 児童を追加」ボタンを、テーブル直下フッターに「＋ 児童を追加」ボタンを配置し、名簿行とボタンが離れすぎない最適な視認性・操作性を実現。<br/>・**児童削除確認ダイアログ**: 児童行の「×」削除ボタン押下時、児童名を表示して確認ダイアログ（`confirm('児童「' + name + '」を名簿から削除しますか？')`）を表示。キャンセル時は削除を中断。<br/>・新規追加時は直前児童の班名を自動継承。<br/>・ソート優先順位: **① 班（自然順）**、**② 班長 → 副班長 → その他**、**③ 学年（6年→1年降順）**、**④ 住所（自然数値順）**、**⑤ クラス（自然数値順）**、**⑥ ふりがな（氏名を代替）**。<br/>・名簿最下部に「班の児童数」と「地区全体の児童数」および学区外児童数を自動併記。 |
| **E-02-06 自地区帳票の選択印刷＆個別PDF保存パイプライン** | ・**一括印刷**: 「🖨️ チェックした自地区帳票を印刷 / PDF保存」により、選択した帳票を連続改ページでまとめて印刷。<br/>・**個別PDF保存（`printSingleDistrictSeparately`）**: 「📄 選択した帳票を個別にPDF保存」ボタンを新設。チェックした各帳票（児童名簿、自治会役員名簿、校外役員学校用、校外役員PTA用）ごとに順次印刷プレビューを呼び出し、帳票ごとの単一PDFファイルとして分割保存可能。<br/>・**動的タイトル連動**: 各帳票の印刷実行直前に `document.title` を「`[帳票名]_[地区名]`」に一時変更し、PDF保存時のデフォルトファイル名が帳票名に自動連動。印刷後に自動復元。 |
| **E-02-07 旗振り当番シフト表（ハタフロットネイティブ統合・永続化・レスポンシブ）** | ・**データと設定の完全永続化**: `saveDistrictLocal()` 実行時に、画面上の入力値（タイトル、場所、時間、期間、向き、段数、ヘッダー、フッター、連絡先、祝日、特別枠）を確実に収集して `currentDistrict.hata` に同期し、LocalStorage（`kogai_district_v2`）および暗号化ファイルへ完全永続化。次回起動時・ファイル読込時にも確実に画面復元。<br/>・**デフォルト設定の最適化**: 印刷向きのデフォルトを「縦向き（`portrait`）」、段数のデフォルトを「2段（`layoutColumns: 2`）」に設定。<br/>・**レスポンシブUI改善**: スマホ画面での「テキスト形式（旧連携機能）」のテキストコピー行を縦並び（`flex-direction: column`）にしテキストボックスの狭小化を解消。操作ツールバー（シフト生成、印刷、読込、保存ボタン）をスマホ画面で整然とした均等グリッド/縦並びブロックに再編。<br/>・**PC表示時の2段グリッド化**: 除外祝日・行事日、特別追加枠、ヘッダー連絡事項、フッター連絡事項＆連絡先を、PC表示時に2カラム×2段グリッドレイアウト（上段: 祝日＋特別枠、下段: ヘッダー＋フッター）に分割し、大画面での視認性・入力性を大幅向上。<br/>・**PDF保存時の動的タイトル連動**: `printHataSchedule()` 実行直前に、`document.title` をシフト表タイトル（`hata.title`、例: `登校見守り活動シフト表`）に動的変更し、PDF保存時のデフォルトファイル名がアプリタイトルではなくシフト表タイトルになるよう改善。印刷後に自動復元。<br/>・**A4組版仕様**: 作成日、2行メタ情報テーブル、ヘッダー連絡事項、多段組（1〜6段、空行パディング整列）、状態別行（祝日グレー、特別枠オレンジ・★）、フッター連絡事項、破線枠校外委員連絡先、当番回数集計アコーディオン、公式JSON双方向連携。 |
| **E-02-08 地区データ保存・読み込み・年度更新（ジャンル別4大セクション整理）** | ・カード6の内部を機能ジャンルごとに明瞭に区切られた4大セクションとして整理・レイアウト：<br/>　**① パスワード設定・端末記憶**: ファイル保護用パスワード（12文字以上、可視化トグル、全角サニタイズ）、確認入力、端末暗号化ストレージ連動記憶チェックボックス。<br/>　**② 地区データの保存・出力・外部共有**: 「💾 ファイルを保存（.txt）」、「📱 LINEで共有」、「✉️ メールで送信」、「🔗 共有（Web Share）」、「📋 暗号化テキストをコピー」。暗号文が2,000文字を超える場合は自動でクリップボード退避＋定型文起動。<br/>　**③ 地区データの読み込み・復元**: 「📂 ファイルから読み込み」、「📥 貼付テキストから読み込み」。**既存hata保護マージ**: 読み込んだデータに `hata` がなく、ローカルに既存 `hata` がある場合は上書き消去せず保護・維持。<br/>　**④ 年度更新（新年度化）**: 「🌸 新年度へ更新（進級・卒業・役員初期化）」。6年生自動削除、1〜5年生進級、旧役員欄・記憶パスワードの安全クリア。**hata年度更新**: 活動場所・時間・曜日・連絡事項等の基本設定は維持し、期間・スケジュール・個別調整・特別枠を新年度用に安全初期化。 |

## E-03 校外代表モード

| 機能名 | 要件・動作仕様 |
| :--- | :--- |

## E-06 データ統合・情報共有の境界

- **E-06-01**: 地区→代表は旗振り設定（hata/hatafurotto）と記憶パスワードを除外する。代表→地区は対象地区だけを出力し、他地区・外部関係者・座席設定を含めない。地区読込データに旗振り設定がない場合は既存設定を維持する。
- **E-06-02**: 自治会は地区名不一致を確認してから置換する。転入児童は地区・班を割り当て、重複時に確認する。取消は旧状態を維持し、成功件数へ含めない。
- **E-06-03**: ファイルと貼付は同じ種別振分・復号・確認を通す。代表マスターは全体復元、地区は集約、転入は割当、自治会は自治会名簿の統合とする。
- **E-06-04**: 自治会年度更新は役職、代表年度更新は外部関係者の区分・所属・役職だけを保持し、正式個人項目を空にする。旧形式name/kanaと余剰連絡先・任意項目も引き継がない。取消時はすべて保持する。更新後の画面・保存・再読込・印刷・再暗号化出力で旧個人項目が復活しない。

### 6.3 PDF保存時の動的タイトル連動仕様 (Dynamic PDF Document Title)
1. **課題意識**:
	- ブラウザ標準の「PDFとして保存（Print to PDF）」機能では、出力されるPDFファイルのデフォルトファイル名として、ブラウザタブの `<title>` タグ（`document.title`）の値（例: `小ptidocs` や `kogaidocs`）が自動採用される。
	- これにより、役員が各種帳票や旗振りシフト表をPDF保存した際、ファイル名がすべて同一のアプリ名称となり、どのファイルがどの帳票であるかをファイルマネージャー上で手動リネームしなければならない運用負荷が発生していた。
2. **動的タイトル一時置換パイプライン**:
	- 各種印刷関数（`printHataSchedule()`, `printSingleDistrictSelected()`, `executeRepSelectedPrint()`, `printNeighborRoster()`, `printNeighborTentCards()` 等）の実行直前に、現在の `document.title` を退避した上で、出力帳票名および地区名を含む適切なファイル名用タイトルへ動的に一時置換する。
	- **命名パターン**:
		- 旗振りシフト表: `${hata.title || '旗振り当番シフト表'}_${districtName}`
		- 児童名簿: `児童名簿_${districtName}`
		- 自治会役員名簿: `自治会役員名簿_${districtName}`
		- 校外役員名簿（学校用）: `校外役員名簿_学校提出用_${districtName}`
		- 校外役員名簿（PTA用）: `校外役員名簿_PTA提出用_${districtName}`
		- 定例会名札: `四つ折り名札_${districtName}`
		- 代表モード一括: `校外代表帳票_${selectedSummary}_${dateStr}`
	- `window.print()` 呼出完了後、同期的に（および `onafterprint` またはタイマーによるフォールバック保護付きで）元の `document.title` へ確実に復元する。

### 6.4 複数帳票の個別PDF保存パイプライン (Granular Separate PDF Export)
1. **課題意識**:
	- 地区役員モード等において複数の帳票（児童名簿、自治会役員名簿、校外役員学校用、校外役員PTA用）にチェックを入れて印刷を実行すると、紙の印刷時には一括出力が便利である一方、PDF保存の際にはすべてが1つの巨大なPDFファイルに結合されてしまう。
	- 学校へ提出するファイル、PTAへ提出するファイル、自治会へ共有するファイルは配布先が異なるため、帳票ごとに分割された単一PDFとして保存できる仕組みが強く求められていた。
2. **個別PDF保存パイプライン（`printSingleDistrictSeparately`）**:
	- 「🖨️ チェックした自地区帳票を印刷 / PDF保存」（一括出力）ボタンの隣に、「📄 選択した帳票を個別にPDF保存」ボタンを新設。
	- チェックされた各帳票を配列化し、1帳票ずつ `#print-area` にレンダリングし、対応する動的タイトルを設定して順次 `window.print()` を起動。
	- ユーザーがブラウザの印刷/保存ダイアログで保存を完了するごとに、次の帳票の保存ダイアログが立ち上がり、チェックを入れた全帳票を個別のPDFファイルとしてスムーズに保存可能とする。

## E-08 パスワード・暗号化提出・端末保存・ロック

- **E-08-01**: パスワードは最低12文字、ASCII U+0021〜U+007Eである。大文字・小文字・数字・記号の混在そのものは必須としない。空白・日本語を許可しない。確認不一致は出力しない。可視化、全角ASCIIの半角化、非ASCIIの除去とカーソル位置保持を行う。
- **E-08-02**: 提出本文は `BEGIN_DATA:` と `:END_DATA` の間に暗号文を置く。誤鍵・短すぎる暗号文・未知形式・改竄は失敗とし、平文へ切り替えない。ファイル名と平文ヘッダーには地区・班・出力日、転入ファイル名には先頭児童の姓が含まれ得る。本文の暗号化はこれらを秘匿しない。
- **E-08-03**: 端末保存は未暗号化状態では平文である。利用者が暗号化を有効にすると地区・代表・自治会・転入の全4モードを保護する。途中失敗は旧値を保持し、暗号化済み表示にしない。全消去後に待機中の旧自動保存でデータを復活させない。
- **E-08-04**: 暗号化解除はパスワードまたは対応環境のWebAuthn PRFで行う。誤認証、保存改竄、いずれかのモードの不正構造は部分表示せず失敗する。Web Locks非対応環境では暗号化の設定・解除・保存等を拒否して対応ブラウザを要求する。
- **E-08-05**: 記憶パスワードは暗号化解除中に明示同意した場合だけ保持する。未暗号化保存・代表集約へ渡さず、地区年度更新では保存対象から除外し、ロックではメモリと入力欄から消去する。暗号化保存済みの値は正しい解除後に復元できる。登録済みストレージの認証を共用し、パスワード記憶のための別WebAuthn登録は行わない。
- **E-08-06**: ロックは鍵、4モードの個人情報、旗振り表、座席・外部関係者、編集下書き、印刷領域、全パスワードと貼付を消去する。再起動・手動・15分非操作後の最初の操作でも強制し、期限切れ後の操作で延長しない。他タブの保護変更・全消去を検知したタブも破棄する。

## E-09 不信入力と失敗時の保全

- **E-09-01**: 認証済み暗号文の中身も不信入力である。ファイル/貼付、公式JSON、平文/暗号化保存値を同じ制約で検証する。型不一致、予約キー、容量・深さ・件数超過、不正な座席寸法を拒否する。上限値は内部仕様I-03で定める。
- **E-09-02**: 旗振り開始日・終了日は、片側だけの入力でも空でなければ実在する `YYYY-MM-DD` を要求する。両側指定時は開始日以下でない終了日、3,660日以内とする。休日省略時の自動補完は開始年2000〜2099だけで実行し、翌年補完も2099までとする。範囲外の有効な日付は受け入れ、休日は空へ補完する。明示した休日と空文字は維持する。対象年の制限は技術上の実行範囲であり、法改正・特例を含む暦の正確性保証ではない。
- **E-09-03**: 取込失敗時は旧4モード・DOM・保存原本を維持し、エラーを通知する。ロック・全消去をまたぐ非同期結果は反映しない。公式JSONの成功・失敗ともファイル選択をクリアして再選択を許す。地区貼付欄は成功時だけ消去する。
- **E-09-04**: 氏名・住所・メモ等のタグ、引用符、イベント風文字列は通常文字列として表示・印刷・保存する。攻撃DOM・コード・暗黙の送信先にしない。アプリURL共有には名簿、パスワード、暗号化本文を混入させない。

仕様と実行結果は[トレーサビリティ](specification_traceability.md)で区別する。OS印刷・共有先・実認証器とHTTP配信での挙動はローカルUI試験だけで保証しない。
