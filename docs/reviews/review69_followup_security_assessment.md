## 台帳と脅威境界

保護対象は全4モードの名簿、端末鍵、設定・解除・提出パスワード、旗振りの担当者と印刷・共有内容である。入口はフォーム、URL、暗号化ファイル・貼付、公式JSON、旧平文・暗号化保存、別タブ通知、ブラウザ引き継ぎ、SWメッセージである。出力は通常DOM、属性、印刷、ローカル保存、ダウンロード、クリップボード、OS共有、LINE/mailtoと公開資産取得である。既存の共有検証・エスケープ・固定イベント・CSP・AAD・排他・世代照合を維持し、既存攻撃試験も全体で再実行する。

| ID | 重大度・成立条件・影響 | 追加試験・是正設計 |
| --- | --- | --- |
| SEC-22 | 中。設定・解除の暗号処理中に閉じる/モード移動/新しい解除を開始すると、旧処理が後から鍵を有効化し、新規入力を保存済み内容で置換し得る。 | 実WebCryptoを待機させ、実クリックで家庭情報へ移動し、新規入力後に旧処理を完了させる。保存値不変・鍵未開放・新規入力保持・旧通知不発生を検査する。UI操作世代と暗号側の確定直前guardを連携する。 |
| SEC-23 | 中。提出ファイル暗号化の完了前にロック・全消去すると、旧名簿の出力・共有が後から発火し得る。暗号化本文の解読成功とは別の、ロック後の情報出力の問題である。 | 全モードのファイル・コピー・共有・地区切出しを横断し、暗号化を遅延した後のロックで出力なしを検査する。開始時保存世代を出力直前に照合し、拒否時に旧データをコピー欄へ戻さない。既にOSへ渡した出力は撤回できない。 |

フォーム外選択制御、パスワード欄破棄、平文書込拒否、モード切替中のゲート、保存拒否・原子性、非同期バージョン応答、固定公開資産だけのSW応答を追加点検する。OS画面取得・クリップボード履歴・ブラウザ拡張・TLS/配信ヘッダー・実認証器はWebコードの自動試験だけでは保証しない。HTTP実起動の環境制約は通常改修の検証記録と分けて保持する。


SEC-24（低）: 地区出力の暗号化中に地区名・班を編集すると、本文は開始時、ファイル名・見出しは完了時の値となる。ファイル・共有の先行単体2件で再現した。宛先識別の混乱を防ぐため、識別情報も本文の取得時点に固定する。ログは `/tmp/kogaidocs-output-snapshot-red.log` である。


SEC-23の再点検では、保存世代だけでは別タブのstorage通知前の認証情報削除を検出できないことを先行単体で再現した。認証メタデータの開始時スナップショットも出力直前に比較し、取得・照合例外も拒否する。先行ログは `/tmp/kogaidocs-output-auth-red.log` である。
