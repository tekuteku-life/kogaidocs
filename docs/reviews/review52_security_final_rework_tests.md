# セキュリティ最終手戻り先行テストレビュー（Gate 2・第2回）

## 対象

- 共有Web Locksによる保存領域の並行処理制御
- 旗振り休日・特別枠の展開後合計件数

## レビュー経過

1. 初回レビューでは、旧形式移行、両解除方式、生体認証情報更新、Web Locks非対応環境、および基本期間未入力時の日付展開検査が不足していたためREWORKとした。
2. 共有LockManagerを用い、初期暗号化、平文保存、暗号化保存、読込、全消去、再設定、旧形式のパスワード・WebAuthn移行、生体認証情報更新の待機と直列化を追加した。
3. Web Locks非対応時に暗号化操作を拒否して保存値を保持し、未暗号化の単一キー読込・保存・全消去だけを許可する検査を追加した。
4. 休日・特別枠について、範囲、重複行、配列と文字列の組合せ、基本期間の省略・空文字を含む3,660件の正常境界と3,661件の拒否を追加した。
5. ファイル、貼付、平文保存、新旧暗号化保存、パスワード・WebAuthn解除で、拒否時に全4モード、DOM、保存値を保持することを確認対象とした。

## 実装前結果

- Web Locks関連は71件中49件合格、未実装を示す22件がRedである。
- 日付展開関連は53件中5件合格、未実装を示す48件がRedである。
- Redは対象実装の欠落に起因し、構文エラーや未処理Promise拒否によるものではない。

## 判定

PASS
