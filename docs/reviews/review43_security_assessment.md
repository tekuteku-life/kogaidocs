# セキュリティ専用アセスメント・是正記録

実施日は2026年10月21日、基点は `00ccda6`、作業ブランチは `fix/security-assessment` である。機能追加の評価とは別に、システム、テスト、実装をセキュリティ観点で点検する。

## 保護対象と成立条件

保護対象は児童・役員の氏名、連絡先、世帯、出欠、旗振り、提出用パスワードと端末暗号鍵である。攻撃者は、悪意ある名簿/JSONの提供者、既存・改竄保存値の混入者、暗号文を読取・差替えできる者、共有端末の利用者を想定する。通常の正規操作で複数タブを併用する場合も境界である。

保存領域や配信ソースを完全制御する攻撃者、侵害済みブラウザ拡張・OS、解除済み端末で任意コードを実行する者をクライアント側暗号化だけで排除できない。AADを持たない旧形式では、移行前に差替え済みの暗号文の元モードを事後に暗号学的確認することはできない。移行時の型検証と移行後の保存先認証を区別する。未暗号化保存は既存の明示された任意運用であり、その場合は端末内の平文を秘匿しない。暗号化設定後の無断な平文への降格は許容しない。

## 是正結果

SEC-01〜SEC-17はすべて是正済みである。主要な変更は次のとおりである。

- 保存値・復号値・ファイルを同じ不信入力として扱い、全4モードを状態変更前に検証する原子的復元へ統一した。JSON・ファイル容量、深さ、配列件数、総ノード数、日付展開、座席寸法を制限し、予約プロパティを拒否する。
- HTML本文・属性・印刷出力を文脈別にエスケープし、座席寸法を描画側でも数値固定した。動的・静的なインラインイベントを固定アクション表へ移し、CSPでインラインscript・イベント、base変更、フォーム送信、objectを拒否した。
- 保存暗号文を保存キーにAADで束縛し、認証メタデータとメモリ鍵を同一セッションへ束縛した。全モード認証後の原子的解除、他タブ変更時の破棄、古い非同期保存の拒否、絶対期限による自動ロックを実装した。
- PBKDF2-HMAC-SHA256は新規保存鍵ラップと`ENC:2:`提出形式で600,000回とした。旧100,000回形式を読込可能とし、パスワード解除時に全モデル検証と同じトランザクションで移行する。生体認証解除時は旧パスワードラップを保持し、次回パスワード解除まで移行を保留する。
- Service Workerはscope内の固定公開資産だけを匿名・no-storeで取得し、非公開応答、未知URL、クエリ、認証付き要求を永続化しない。cacheおよび登録解除は当該アプリのscopeへ限定した。
- 平文保存・共有読込を含む保存操作を同一Web Locks名で直列化し、複数キー確定と復元を排他区間内で完了する。`localStorage.clear()` の全消去通知も保護状態の消失として扱い、Web Locks非対応時は暗号化操作を拒否する。
- 旗振りの休日・特別枠は基本期間の有無にかかわらず範囲展開後の合計を3,660件以下に制限し、3,661件以上を全復元経路で状態変更前に拒否する。
- 地区データの任意機微項目 `savedFilePassword` は存在時に文字列だけを許可し、不正型をファイル・貼付・平文保存・暗号化保存の共通受入境界で拒否する。
- 旗振り設定は描画が読む標準項目と別名を共通の文字列型台帳で検証し、`scheduleCreatedDate`・`district` を含む不正型を状態確定前に拒否する。
- 保存要求は呼出時点の直列化結果とセッション世代を保持し、全消去・再設定・ロックをまたいだ待機保存を拒否する。実ChromiumのWeb Locksで、全消去後に旧地区データが平文復活しないことを検査する。

## 残余リスクと検証範囲

- CSPはHTML metaで強制しており、`frame-ancestors`は実配信HTTPヘッダーで設定する必要がある。TLS、HTTP応答ヘッダー、ホスティング設定はローカルリポジトリ検査の対象外である。
- Fetchのfiltered responseでは`Set-Cookie`がJavaScriptから見えない。SWの安全性は固定許可リスト、匿名要求、公開応答の配信契約に依存し、ヘッダー検査だけを保証根拠としない。
- 実OSのWebAuthn認証器、実印刷、共有先アプリ、実配信環境でのオフライン更新は自動テスト対象外である。WebAuthn PRFのAPI契約、失敗処理、鍵ラップはモックと実WebCryptoで検査済みである。
- JavaScriptから所有する生鍵ArrayBufferはfinallyでゼロ化するが、ブラウザ内部コピーとGC済み領域の消去までは保証しない。
- 未暗号化保存を利用者が選択した場合、端末内LocalStorageは平文である。暗号化設定後に無断で平文へ降格する経路は拒否する。

以上により、ローカルで検証可能なセキュリティ指摘はすべて解消し、残余リスクを明示した状態で合格と判定する。
