## 1. 脅威モデルおよび入力・出力台帳

- **保護対象資産**:
	1. 各地区役員・校外代表・自治会役員・家庭情報入力（新入生・転入生）の名簿データ（児童名・住所・電話番号・メールアドレス・世帯情報・学区外情報）。
	2. 端末暗号化用マスター鍵（`activeStorageKey`）、生パスワード、記憶パスワード（`savedFilePassword`）、認証メタデータ（`kogai_auth_meta`）。
	3. ロック中画面・再起動後画面・出力帳票（`#print-area`）・クリップボード・ダウンロードファイル・外部共有URLへの出力内容。
- **信頼境界および攻撃者能力**:
	- ローカル保存された暗号文・平文、外部から持ち込まれる提出 `.txt`・貼付テキスト・公式JSON・ブラウザ間引き継ぎデータ、`version.json` 応答、Service Worker `message` / `fetch` イベント、同一端末・同一オリジン別タブ操作をいずれも不信入力または競合主体として扱う。
	- 暗号処理中・保存中・印刷中のユーザーキャンセル、画面遷移、ロック、全消去、タブ間ストレージ改変との競合を検証対象とする。
	- Webコードで制御できない境界（OSスクリーンショット、OSクリップボード履歴、ブラウザ拡張機能、実配信HTTPS/TLSヘッダー、実機OS認証器）は残余リスク・未検証境界として区別する。
- **入力経路**:
	- HTMLフォーム（短文/長文入力、パスワード欄、ファイル選択）、URLクエリ（`?mode=`, `openExternalBrowser`）、暗号化 `.txt` / 貼付テキスト（`parseTxtContent`）、公式JSON（`loadHataOfficialFile`）、ブラウザ引き継ぎ（`restoreBrowserHandoff`）、LocalStorage（`loadStorageDecrypted`）、`storage` イベント、`version.json` fetch 応答、Service Worker `fetch` / `message` イベント。
- **出力経路**:
	- 通常DOM描画、`#print-area` 印刷出力、`localStorage` 書込み、`.txt` ダウンロード（`downloadTextFile`）、クリップボードコピー（`navigator.clipboard.writeText` / フォールバック選択欄）、Web Share / LINE / `mailto:` 起動。

## 3. 未検証境界・残余リスクの明記

本ローカル評価および自動テスト（単体・結合・SW・実Chromium CDP）は、Webアプリケーションコード内の境界を検証するものであり、以下は別途実環境確認を要する残余リスク・未検証境界とする。
- 実HTTPS本番配信におけるTLS構成およびHTTPレスポンスヘッダー（CSPヘッダー、HSTS、`X-Content-Type-Options` 等）。
- 実機 iPhone / Android における Safari / Chrome PWAインストール、WebAuthn実生体認証器（Touch ID / Face ID / Windows Hello）、OSネイティブ印刷・共有ダイアログの挙動。
- OSレベルの画面収録・スクリーンショットおよびOSクリップボード履歴の制御。
