# セキュリティ最終手戻り設計レビュー（Gate 1）

## 対象

- `docs/system_design.md` 10.6「セキュリティ専用是正設計」
- 別タブの全消去通知、複数キー保存競合、旗振り日付展開上限の共通受入境界

## レビュー経過

1. トランザクションマーカー案は、照合とLocalStorage変更の間へ別タブ処理が入るためREWORKとした。
2. 暗号化処理だけをWeb Locksで排他する案は、初期暗号化と別タブの平文保存が競合するためREWORKとした。
3. 平文状態を含む通常保存・読込・全消去と全暗号化操作を同一名Web Locksへ統一し、ロック取得後に保護状態を再評価する設計へ改訂した。
4. Web Locks非対応環境では暗号化操作を拒否して平文へ降格しないこと、`localStorage.clear()` の通知で保護セッションを無効化することを確認した。
5. 旗振りの休日・特別枠は範囲展開後の合計3,660件を共通受入境界で検査し、全復元経路で状態変更前に拒否することを確認した。

## 判定

PASS
