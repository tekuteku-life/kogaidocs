# 追加要件：JSON保存廃止とLINE内ブラウザからの引き継ぎ

## 方針

開発者はハタフロットとkogaidocsで同一であり、今回追加した第三者ライセンス通知を削除する。ハタフロットJSONは読込専用とし、出力ボタン・イベント・シリアライザーを削除する。旗振り設定の保存先は地区の暗号化ファイルとブラウザ引き継ぎデータである。

LINE内ブラウザはUAの `Line/<version>` を検知して警告する。UAが変更・抑制された場合に完全な検知はできない。通常ブラウザを開くURLは同一アプリのorigin/pathと固定モードだけから構築し、`openExternalBrowser=1` を付ける。個人情報・暗号文・鍵・任意の元URLパラメーターは含めない。LINE公式の仕様は [外部ブラウザを開く指定](https://developers.line.biz/en/docs/messaging-api/using-line-url-scheme/#opening-a-url-in-an-external-browser) による。実際のアプリ間遷移はLINEの版・OSに依存するため、メニューから開く代替手順も表示する。

## 途中入力の引き継ぎ

保存領域を共有しないブラウザ間の移動には、パスワードで暗号化した専用データを用いる。ファイル保存またはコピーを行い、外部ブラウザの常設「ブラウザ間引き継ぎ」から復元する。URLにデータを埋め込まず、サーバーにも送信しない。移動ボタンの前に保存・コピー手順を案内し、未実施の場合は途中入力が自動移動しないことを明示する。

対象は地区（全旗振り設定を含む）・代表・自治会・未完了の転入者フォーム、代表名簿モーダルの未確定編集、貼付欄等の下書き、選択モードである。転入者は提出用の必須入力検査を適用せず、既存の保存用下書き検証を使う。パスワード・生体認証・端末暗号化設定・未読込ファイルは対象外であり、移動先で再入力・再設定する。

復元先の既存データを置換するため、復号・全項目検証後に確認を求める。不正型、誤鍵、過大データ、取消、ロック・全消去、保存失敗では部分復元しない。4モードの書込みは同一Web Lock内で全暗号化を準備してからトランザクションで確定する。書込み失敗時は旧値を戻し、モデルとDOMを変更しない。外部ブラウザの端末暗号化が有効なら同じ方式で再暗号化し、降格しない。

代表の未確定編集は原本と下書きの双方、および座席参照のための旧行indexを保持する。引き継ぎによって「保存して閉じる」を暗黙に実行してはならない。新しいdialogの暗号処理にも処理世代を持たせ、閉じる・ロック後に古い処理が結果を表示しないようにする。

## 検証

先行テストでLINE/通常UA・安全な移動URL・全モード下書き・不正データと原子的保存を検証する。実ChromiumではLINE型UA、暗号化作成とコピー/保存、別ブラウザ相当の保存消去後の実ファイル/貼付復元、未完了転入者、代表下書き、取消・誤鍵・ロックを検証する。全既存試験、構文・静的検証・網羅率を確認後、英語メッセージでコミットし、作業ブランチをpushする。実機LINE/Safari間遷移は別の受入確認である。
