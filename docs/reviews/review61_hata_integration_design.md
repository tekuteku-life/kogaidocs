# ハタフロット全機能統合の設計・比較記録

**履歴**: 本書は追加要件前の設計・検証記録である。JSON保存の廃止、ライセンス通知不要、LINE引き継ぎ、pushについては [追加要件の設計](review63_browser_handoff_design.md) と最終検証記録を優先する。

比較対象は [hatafurotto](https://github.com/tekuteku-life/hatafurotto/tree/c5ae5692ea8cdb410b720a006fca6f34f93d5449) の `index.html` である。2026年11月10日に公開ソースを取得して照合した。

| 上流機能 | 既存実装の不足 | 方針 |
| --- | --- | --- |
| タイトル・作成日・地区・場所・複数行時間 | 作成日・印刷地区名の入力なし、時間は単一行 | 全項目を編集可能とし、空文字も保存する |
| 期間・曜日・1〜6段・向き | 曜日入力なし、5・6段の選択なし | 基本設定に曜日を常設する |
| テキスト名簿・重複警告 | 名簿の編集なし、取込名簿を生成時に上書き | 独立した名簿欄と明示的な児童名簿反映ボタンを設ける |
| 休日・特別枠・連絡文・連絡先 | 設定あり、一部消去値の収集が欠落 | 空文字も同期し、再描画・印刷に反映する |
| 均等生成・回数集計・多段印刷 | エンジンあり、PDF名はタイトルのみ | 最新設定で印刷し、タイトル・地区・作成日のPDF名を使用する |
| LINE用シフトコピー | 名簿コピーのみ | 生成シフト・連絡文のコピーと手動コピー欄を提供する |
| JSON保存・読込 | 出力が旧alias形式のみ、地区名が欠落 | 上流の実キーと旧aliasを両立し、全設定を往復する |
| 保存状態・離脱確認 | 自動端末保存のみ | ファイル未保存状態を表示し、明示保存で解除する |

上流の初期サンプル名簿・役員Aの特別枠・仮の夏季/冬季休業日は、実運用の名簿や学校日程と異なるため自動投入しない。同じ休業期間は休日欄の期間入力で設定できる。初期値や外観の完全複製ではなく、上記の利用者機能を既存の名簿・暗号化・印刷の構成へ統合する。

## データとセキュリティ

`hata.members` が未定義の旧データだけ児童名簿から補完する。明示した空文字は空名簿として維持する。`weekdays: []` は曜日選択なしであり、期間内の特別枠のみを生成する。`format`・`dedup` も地区保存に含める。年度更新では印刷地区名・世帯集約設定を保持し、旧年度の名簿・日程・手動調整を消去する。公式JSONは上流キーを優先して解釈し、旧meta接頭辞のキーも読める。

地区の暗号化ファイルは `currentDistrict.hata` 全体を保存する。代表への集約・代表マスターは従来どおり旗振り設定を除外する。全ての新しい描画文字列をエスケープし、取込型検証後に状態を確定する。ロック時は名簿コピー・LINEコピー欄も消去する。

## iPhoneの調査

`apple-mobile-web-app-capable`、status-bar-style、apple-touch-icon、manifestは既存HTMLに存在する。欠落はアプリ名指定とiOS向け操作導線である。iOSでは `beforeinstallprompt` に依存せず、Safariの共有メニューから追加する説明を出す。iPadOSのMac型UAもタッチ数で判定する。通常HTTP/file起動やインストール済み起動では案内ボタンを出さない。

根拠は [Appleの追加手順](https://support.apple.com/ja-jp/guide/iphone/iphea86e5236/ios) と [AppleのWebアプリ設定資料](https://developer.apple.com/library/archive/documentation/AppleApplications/Reference/SafariWebContent/ConfiguringWebApplications/ConfiguringWebApplications.html) である。ChromiumのUA再現は実機Safariのインストール成功を証明しない。

## 検証計画

単体で上流JSON往復・空値・曜日・重複・LINE本文・不正型を検証する。実Chromiumのfile起動でテキスト編集・児童名簿反映の取消・曜日・再描画・暗号化ファイル保存復元・再起動・375px表示・iOS案内を検証する。全既存試験と構文・静的検証も実行する。
