## 4. 仕様確認事項・残余リスク・未検証境界

- 残余（E-14-05）: `frame-ancestors`・`sandbox` は meta では設定できず、配信側の HTTP 応答ヘッダーが必要である。HTTP 配信では `frame-ancestors` と `Cross-Origin-Opener-Policy` の設定を推奨する。CSP で拒否される入れ子文書・フォームの送信でも、ブラウザは宛先の名前解決と接続を先に始めることがある。file 起動では `'self'` がホスト付きの file: URL に一致する（Windows の UNC は未確認）。
- 範囲外: 利用者が操作・設定するブラウザ自身の機能（翻訳など）、WebAuthn のパスキーの提供元の同期、利用者が開いた外部の画面、別のアプリ・拡張機能の通信。`writingsuggestions` に対応しない古い Edge のテキスト予測は、ページからは止められない。
- 字句の固定は、アプリ自身のコードが将来、意図しない外部通信の経路を持ち込むことを検出するもので、任意の難読化は対象としない。
- 配信側の前提（未検証）: docs/・tests/・README.md などを配信側が公開しないこと（E-14-05）。リポジトリの直下をそのまま公開する方式では、これらが CSP のない同一オリジンの HTML として公開されうる。
- 未検証境界: HTTP 配信での実ブラウザの確認（Service Worker の登録・更新、自オリジンのマニフェストの取得）、実機 iOS/Android、Microsoft Edge でのテキスト予測の抑止、Windows の file 起動。
- 外部工程: コミット・リモート push は本記録の後に行う。PR の作成は、この環境に `gh` も API の資格情報もないため、比較 URL と本文を利用者へ渡す。
