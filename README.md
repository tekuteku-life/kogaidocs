# 📋 校外委員会 名簿・帳票・スクールゾーン協議会管理システム

PTA校外委員会（地区役員・校外代表役員）のための、児童名簿・役員名簿・各種提出帳票・印刷・ハタフロット連携・スクールゾーン協議会（スクゾ）座席表を一元管理するWebアプリケーションです。

---

## 🌟 主な特徴

- **🔒 完全ローカル動作＆プライバシー保護**  
  サーバーへのデータ送信は一切行いません。すべてのデータはお使いの端末（ブラウザ）内でのみ処理・保存されるため、個人情報が外部へ漏洩する心配がありません。
- **🛡️ 強力な暗号化セキュリティ（AES-256-GCM + PBKDF2 + WebAuthn PRF）**  
  - 提出用ファイル（`.txt`）は **AES-256-GCM**（半角英数記号12文字以上）で暗号化。
  - 端末内の一時保存データ（LocalStorage）も、パスワードおよび **生体認証（Touch ID / Windows Hello / 指紋・顔認証）** によるハイブリッド暗号化で安全に保護。
- **📲 PWA（Progressive Web App）対応・完全オフライン動作**  
  スマホやPCのホーム画面・デスクトップにアプリとしてインストール可能。体育館や会議室など電波の届かないオフライン環境でもすべての機能が軽快に動作します。
- **🎒 班名リスト＆柔軟な児童名簿**  
  - 地区名の下に班名リスト（例：`1班, 2班, 3班` や `A班, B班`）を登録すると、児童名簿や役員入力のプルダウンから簡単に選択可能。
  - 「班長 → 副班長 → その他」「学年（6年→1年）」「住所」の優先度で自動整列。
  - 児童名簿末尾には「班の人数」と「地区全体の人数」両方の学年別内訳を自動併記。学区外児童フラグにも対応。
- **🚩 ハタフロット連携**  
  児童名簿から「住所の数字（1-2-3など）＋苗字」の旗振り当番用テキストを自動生成。同一世帯の重複行まとめやワンクリックコピーに対応。全角数字の自動半角変換も完備。
- **🏫 スクールゾーン協議会（スクゾ）支援**  
  学校関係者・PTA本部・役所/警察・自治会役員の出席簿作成、A4四つ折り自立型名札（折り線ガイド付）、会場座席表の直感的な配置・印刷に対応。
- **🔄 ワンクリック年度更新**  
  6年生の卒業削除、1〜5年生の自動進級（+1学年）、役員情報の安全なリセットに対応。新旧役員間のスムーズなデータ引き継ぎを実現。

## 📱 PWAアプリのインストール方法

ブラウザから直接アプリとしてインストールすることで、通常のアプリと同様に全画面で快適にご利用いただけます。

- **パソコン（Google Chrome / Microsoft Edge）**:
  - ヘッダー右上に表示される「📲 アプリをインストール」ボタン、またはアドレスバー右側のインストールアイコンをクリック。
- **iPhone / iPad（Safari）**:
  - 画面下部の共有ボタン（四角から矢印が出ているアイコン）をタップ → **「ホーム画面に追加」** を選択。
- **Android（Chrome）**:
  - 画面右上のメニュー「︙」をタップ → **「アプリをインストール」** または **「ホーム画面に追加」** を選択。

## 📖 使い方ガイド

画面上部のタブで「① 各地区役員モード」と「② 校外代表モード」を切り替えて使用します。

### ① 各地区役員モード（地区入力・ハタフロット・地区印刷）

1. **地区名・班名・校外役員情報**
   - 地区名（例：`1丁目`）を入力します。
   - 班名リスト（例：`1班, 2班`）を入力します。
   - 校外役員の氏名・ふりがな・担当班・連絡先・手紙受取用のお子様情報を入力します（2人以上の役員追加も可能）。
2. **自治会役員名簿**
   - 地区と結びつく自治会役員（会長・副会長・防犯部長など）の情報を入力します。
3. **児童名簿**
   - 児童の学年・クラス・班・氏名・住所・電話・役職（班長/副班長）・学区外フラグを入力します。
   - 名簿の一番下にある「＋ 児童を追加」ボタンを押すと、直前の行と同じ班名が自動選択されます。
   - 名簿末尾に「班の集計」と「地区全体の集計」が自動計算されます。
4. **ハタフロット用リスト**
   - 設定したフォーマット（例：`{住所数字} {苗字}`）に基づき変換プレビューが表示されます。
   - 「📋 ハタフロット用リストをコピー」を押してハタフロットへ貼り付けます。
5. **地区用 帳票印刷**
   - 「児童名簿（班・地区集計付）」
   - 「定例会用 四つ折り名札（中央オリセン付）」
   - 「子供経由の封筒宛名（A4・3×4面／子供向けひらがなメッセージ付）」
6. **提出・保存用ファイル（.txt）出力**
   - パスワード（半角英数大文字・小文字・記号の12文字以上）を二度入力し、「💾 提出・保存用ファイル(.txt)出力」をクリックします。
   - 暗号化されたファイル（`地区名_校外役員データ.txt`）が保存されるので、校外代表役員へメールやチャットで提出します。

---

### ② 校外代表モード（全地区集約・スクゾ協議会・選択印刷）

1. **各地区データの集約**
   - 地区役員から提出された `.txt` ファイルを「各地区の .txt ファイルをまとめて追加」から複数一括選択して読み込みます。
   - メール本文などに貼り付けられた暗号化テキスト（`BEGIN_DATA: ... :END_DATA`）の直接貼り付けにも対応しています。
2. **集約済み地区一覧**
   - 読み込んだ地区・班の一覧、役員名、児童数が確認できます。印刷対象のチェックボックスで必要な地区のみ選択できます。
3. **スクールゾーン協議会 出席確認**
   - 学校関係者（校長・副校長）、PTA会長、区役所、警察署、および集約した各地区自治会役員の出席チェックを行います。
4. **スクゾ 座席表レイアウト**
   - 会場配置（行数・列数）を設定し、出席者を座席に割り当てます。
5. **チェック選択式 一括印刷パネル**
   - 必要な書類にチェックを入れ、「🖨️ チェックした帳票をまとめて印刷 / PDF保存」をクリックすると、一括で綺麗に改ページ印刷・PDF保存できます。
   - **出力帳票一覧**:
     - ①-A 校外役員名簿（PTA提出用：役員氏名・児童学年のみ、代表三役連絡先別掲）
     - ①-B 校外役員名簿（学校提出用：住所・TEL・児童情報・地区＋班児童数・学区外児童数入）
     - ② 定例会用 四つ折り名札
     - ③ 子供経由の封筒宛名
     - ④ 地区別 児童名簿（地区名＋班名ごとに改ページ、班・地区集計併記）
     - ⑤ 地区別 自治会役員名簿（重複排除・地区結びつき）
     - ⑥ スクゾ用 四つ折り名札
     - ⑦ 出席簿1（学校関係者・PTA本部・校外委員）
     - ⑧ 出席簿2（役所関係職員・自治会代表）
     - ⑨ 出席簿3（当日追加記入用空白）
     - ⑩ スクゾ 座席表
     - ⑪ 代表控え用 スクゾ関係者名簿（連絡先入）

## 🔐 セキュリティ・データ保護機能

### 1. 端末内保存（LocalStorage）の暗号化
ブラウザ内に自動保存される個人情報データは、標準で暗号化保護に対応しています。
- **暗号化の有効化**:
  - ヘッダーの「🔓 ストレージ未暗号化」バッジをクリックするか、カード6の「🛡️ このパスワードでブラウザ内データも暗号化保護する」をクリックします。
  - パスワードを入力し、「生体認証も有効にする」にチェックを入れることで、**WebAuthn PRF** による鍵ラッピングが行われます。
- **次回以降のロック解除**:
  - ページを開いた際、登録済みの生体認証（Touch ID / 顔認証 / Windows Hello）を1タップするだけで瞬時にロックが解除されます。
  - 生体認証非対応の端末やブラウザでも、パスワード入力で安全に解除できます。
- **安全なメモリ管理**:
  - 復号用のマスターキーはブラウザのメモリ内でのみ保持され、タブを閉じると自動的にロックされます。

### 2. 提出用ファイル（.txt）の暗号化
- 地区から代表へ提出するファイルは、Web Cryptography API による **AES-256-GCM** で暗号化されています。
- 新規暗号化にはPBKDF2-HMAC-SHA256（600,000回ストレッチング、暗号論的擬似乱数ソルト・初期化ベクトル）を採用している。旧100,000回形式は読込後に安全な新形式へ移行する。

## 🔄 年度更新（新年度化）の手順

新年度への引き継ぎ時は、以下の手順で行います：

1. 現在のデータをバックアップのため「💾 提出・保存用ファイル(.txt)」として保存しておきます。
2. 「🔄 年度更新（新年度化）」ボタンをクリックします。
3. 自動的に以下の処理が行われます：
   - 6年生の児童データが自動削除されます。
   - 1年生〜5年生の児童が自動的に +1 学年進級します（5年生→6年生、1年生→2年生など）。
   - 任期満了に伴い、校外役員一覧・自治会役員一覧が初期化されます。
4. 新1年生の情報を児童名簿に追加し、新役員情報を入力して新年度の作業を開始します。

  - Google Chrome（Windows / macOS / Android / ChromeOS）
  - Apple Safari（iOS / iPadOS / macOS）
